⚙️ LINE接続設定

① LINE Developers で準備すること
  1. LINE公式アカウントで Messaging API を有効化し、LINE Developers のチャネルを開く
  2. 「チャネル基本設定」の チャネルシークレット と、「Messaging API設定」の チャネルアクセストークン（長期） を下に貼る
  3. 「Messaging API設定」の Webhook URL に下のURLを登録し、Webhookの利用をON（「検証」ボタンで成功を確認）
  4. LINE公式アカウント管理画面で あいさつメッセージ・応答メッセージをOFF（ONのままだと挨拶と1通目が二重に届きます）
② 認証情報
伏せ字のまま保存すると変更されません。
③ 配信の設定
